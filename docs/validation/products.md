## 本次覆盖

- 教材、自行车、数码异构属性及当前可读取的分类规则；必填、数值/布尔/字符串/数组类型错误、额外属性数量、键/字符串/数组长度、嵌套对象/数组、null 与保留标准字段拒绝。
- 默认限制允许边界长度、16 项额外属性和混合标量数组；四档统一新旧程度均可发布。图片 0/1/9/10 项与 file/FTP/相对地址/缺失主机/凭据/过长 URL，价格精确整数分、非正数/小数/超界拒绝，最大合法价格可往返读取。`example.invalid` 地址成功发布，验证没有可达性依赖。
- 缺失、伪造及过期身份拒绝；所有权来自令牌，拒绝请求伪造卖家、期限和其他未知标准字段。他人不能修改商品。内容替换遵守当前分类规则并保持身份、首次价格、当前价格、发布时间及到期时间不变；售出、到期或资格移除后不能修改，档案仍可读取。
- 规则新增必填属性后历史商品仍可读取；新发布和内容修改拒绝旧属性集合，符合新规则的修改可持久读取。降低数量限制后后续写入拒绝，旧数据仍能读取。
- 发布商品和独立在售资格通过同一 MongoDB 事务提交；对资格集合设置拒绝写入的数据库 validator，让第二次写入真实失败。API 返回 503 后档案与资格都为零，解除故障后发布成功，档案与资格的到期时间一致。期限精确为 1440 小时。
- 单次详情包含全部商品字段、图片、当前卖家资料及信用分；修改卖家资料后详情即显示新资料，不泄露密码哈希。新商品价格历史为空，首次挂牌价独立保留；既有历史夹具只展示最近 5 次，完整入口可分页取得全部记录，相同时间按 ID 倒序，不重复、不遗漏，不混入其他商品历史。
- OpenAPI 包含分类、发布、内容修改、详情、只读历史路由、认证要求、金额/图片/新旧程度及输入限制。Swagger HTML 使用现有 Bearer Authorize 入口。
